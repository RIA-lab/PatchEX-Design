# PED-Eval

Utilities for evaluating designed enzyme sequences for the PatchEX-Design project.

## Python compatibility

`PED-Eval` supports Python 3.8 and newer.

## Installation

Base package:

```bash
pip install -e ./PED-Eval
```

With predictor and structure extras:

```bash
pip install -e "./PED-Eval[predictors,structure]"
```

## Command-line entry point

After installation, the package exposes:

```bash
ped-eval --help
```
